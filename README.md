# SpaceX Falcon 9 Data Science Capstone

## Project Overview

This project analyzes SpaceX Falcon 9 rocket launches to understand the factors that may influence launch success. It uses data collection, data wrangling, exploratory data analysis (EDA), SQL queries, interactive visualizations, and machine learning classification.

The goal is to explore launch patterns and use historical data to predict whether a Falcon 9 launch will be successful.

## Objectives

- Collect SpaceX launch data using the SpaceX API.
- Gather additional launch information through web scraping.
- Clean and prepare the collected data for analysis.
- Perform exploratory data analysis using Python, Pandas, and Matplotlib.
- Analyze launch data using SQL queries.
- Visualize launch locations using Folium.
- Build an interactive dashboard using Plotly Dash.
- Train and evaluate machine learning classification models.
- Identify insights related to launch outcomes.

## Project Workflow

### 1. Data Collection
Collect historical SpaceX launch information through API requests and web scraping.

### 2. Data Wrangling
Clean the collected data, handle missing values, select relevant features, and prepare the dataset for analysis.

### 3. Exploratory Data Analysis
Use visualizations to explore launch success, payload information, launch sites, and yearly trends.

### 4. SQL Analysis
Use SQL queries to investigate launch records, payloads, launch sites, and success rates.

### 5. Interactive Visualization
Use Folium to map launch locations and Plotly Dash to explore launch outcomes through interactive charts.

### 6. Predictive Analysis
Train and evaluate classification models to predict launch outcomes using the prepared dataset.
